Learn how it works

Smart Buddy is made from a few well-known tools. Understand each one and you can build your own screens.

🧩

LVGL

A free graphics library for embedded screens. It draws buttons, lists, calendars, charts and animations, and handles touch input. Smart Buddy's whole interface is built with it.

🖥️

LovyanGFX

The display driver layer. It talks to the RGB panel and the touch chip so LVGL can put pixels on the 800×480 screen at a good frame rate.

✏️

SquareLine Studio

A drag-and-drop designer for LVGL. Design screens visually, then export C code. Elecrow supports it directly for this board.

A screen, a web page and a local network are enough to build a product that real shops and offices will pay for. Here are ideas you can start with.

Restaurant order screen

The ESP32 hosts the menu as a web page. Customers scan a QR code at the table, add items to the cart and place an order. The order appears on the screen in the kitchen or at the counter, with a new-order alert.

Sell to restaurants, dhabas, food courts

How to make money from it

Build the product once, then sell it many times. Charge a one-time setup fee for the hardware and installation, and a small monthly fee for menu updates, support and new features. Think about it, build it, and ship it: your first customer is usually one shop away.

Pick a model that fits your customers. You can start with one and add the others later.

Build your own version with Claude

The Desk Buddy ZIP already has the correct libraries, display setup and frame rate. Give that ZIP to Claude with a good prompt and it can build your idea on top of a working base.

How to do it

  1. Download the ZIP from the GitHub repo using the button below.
  2. Open Claude and start a new chat.
  3. Attach the ZIP to the chat.
  4. Pick your idea on the right, edit it if you like, then copy the prompt.
  5. Paste and send. Claude reads the ZIP and builds a new project for your idea.

Why the ZIP matters: it keeps the exact library versions, pin setup, display configuration and frame rate that already work on your board. Claude reuses them instead of guessing.

Having trouble?

Common problems and quick fixes.

The screen stays black

Check that PSRAM is set to OPI PSRAM and the partition scheme is Huge APP. Power the board with 5V 2A. Make sure your LVGL, LovyanGFX and ESP32 core versions match the project.

I get a compile error

Install ESP32 core exactly 2.0.14. Copy the project's library contents into your Arduino libraries folder and restart the Arduino IDE.

The web page does not open on my phone

The phone and the display must be on the same Wi-Fi. Type the IP address shown on the screen into your browser with http:// in front. If you use a phone hotspot, keep it on the 2.4 GHz band.

Photos or wallpapers are missing

Format the SD card as FAT32. Keep photos in /SmartBuddy/images/ and wallpapers in /SmartBuddy/backgrounds/. Unsupported or corrupt files are skipped.
